# Nemotron Evidence Suite

Purpose: bounded evidence family for ClosedCode work involving NVIDIA Nemotron as an autonomous coding agent.

Subdirectories:

- `findings/` — proved capabilities, useful behavioral observations, and successful investigation results.
- `bugs/` — confirmed implementation defects discovered through Nemotron-driven or Nemotron-related testing.
- `issues/` — product gaps, interaction limitations, acceptance concerns, and unresolved engineering questions.

This suite is about the ClosedCode/Nemotron product path. It does not replace the general Heavy Engineer audits, incidents, or roadmap.

Historical operation status remains authoritative in the Heavy Engineer audit trail. A later successful Nemotron test does not rewrite an earlier RED/UNKNOWN operation.
